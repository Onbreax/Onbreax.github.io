Matchwork · Version 1.1.7 · 19 octobre 2026

Connecter Gmail sans Google Cloud

Matchwork utilise ton adresse Gmail et un mot de passe d’application Google dédié. Aucun projet Google Cloud, client OAuth ni abonnement supplémentaire n’est nécessaire.

Préparer le compte Google

  1. Active la validation en deux étapes.
  2. Ouvre les mots de passe d’application.
  3. Crée un code nommé Matchwork. Copie le code à 16 caractères ; les espaces affichés sont retirés automatiquement.

Utilise ce code dédié, jamais ton mot de passe Google habituel. Google ne propose pas cette option pour certains comptes, notamment selon la configuration des clés de sécurité, le compte professionnel ou scolaire et la Protection Avancée.

Dans l’APK Android

  1. Installe la version 1.1.7 par-dessus la version précédente.
  2. Ouvre Profil et cible → Alertes emploi Gmail → Connecter Gmail.
  3. Saisis ton adresse Gmail et le code à 16 caractères dans la fenêtre Android.
  4. Choisis si tu veux mémoriser le code, chiffré sur le téléphone, puis connecte le compte.
  5. Appuie sur Récupérer les alertes ou inclus Gmail dans tes recherches habituelles.

La mémorisation utilise Android Keystore et un chiffrement AES-GCM. Le code ne passe pas dans le HTML et ne figure pas dans les sauvegardes Matchwork. Chaque profil conserve son association Gmail.

Dans le HTML sur ordinateur

Un navigateur ne peut pas établir directement une connexion IMAP. Le pack fourni ajoute un petit lanceur local : la connexion à Gmail s’effectue depuis ton ordinateur, sans serveur distant Matchwork.

  1. Télécharge et décompresse le pack HTML avec lanceur local.
  2. Utilise Python 3.9 ou plus récent. Sous Windows, ouvre Lancer-Matchwork.cmd. Sous macOS/Linux, exécute python3 gmail-local.py dans le dossier extrait. Sous Windows, la commande py -3 gmail-local.py fonctionne aussi si le lanceur Python est installé.
  3. Le lanceur ouvre http://127.0.0.1:8765/matchwork.html. Garde sa fenêtre ouverte.
  4. Dans le profil, saisis l’adresse Gmail et le mot de passe d’application, puis clique sur Connecter Gmail.

Le lanceur conserve le code uniquement en mémoire jusqu’à son arrêt. Il le redemande à la session suivante. Il écoute uniquement sur ton ordinateur. Arrête-le avec Ctrl+C.

La version locale et la version web ont des stockages distincts. Pour retrouver tes offres et ton profil, exporte une sauvegarde depuis la version web, puis importe-la dans la version locale. Les identifiants Gmail ne sont pas inclus.

Le HTML seul et la page GitHub restent utilisables pour les autres fonctions ; la connexion Gmail par mot de passe d’application demande l’APK ou le lanceur local. Aucun champ de mot de passe n’est affiché sur la page GitHub.

Ce que Matchwork récupère

La recherche filtre les alertes de jobalerts-noreply@linkedin.com sur 7, 30, 90, 180 ou 365 jours. Elle inclut les messages archivés accessibles dans le dossier Gmail « Tous les messages » et exclut spam et corbeille. Le code utilise une ouverture en lecture seule et la lecture IMAP BODY.PEEK : aucun email n’est envoyé, supprimé, déplacé ou marqué comme lu.

Le mot de passe d’application donne techniquement accès à la messagerie ; le filtre et l’usage en lecture seule sont appliqués par Matchwork. L’extraction des offres ne fait aucun appel à OpenRouter. Les analyses IA restent soumises aux options habituelles.

Un lot traite au plus 200 emails, limités à 2 Mo chacun. Les pièces jointes sont ignorées. Les doublons conservent tes notes et ton suivi. Les alertes donnent des fiches partielles, sans transformer la date de réception en date de publication. Un lot incomplet peut être repris.

Déconnexion et erreurs

Dissocier ce profil retire ses identifiants de cette application et conserve les offres. Pour révoquer le code complètement, supprime-le dans la page Google des mots de passe d’application. Si tu changes ton mot de passe Google, Google révoque les codes existants : crée alors un nouveau code.

Si la connexion échoue, vérifie le compte, le code à 16 caractères et la disponibilité des mots de passe d’application. Si le dossier « Tous les messages » n’est pas accessible en IMAP, vérifie son affichage IMAP dans Gmail. Une erreur réseau conserve les offres déjà importées. Si une reprise est signalée comme ancienne, change la période puis relance.
